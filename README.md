# Анализ эффективности нового алгоритма рекомендаций (A/B-тест)

Домашнее задание по курсу A/B-тестирования. 

Цель работы — проанализировать результаты A/B-теста нового алгоритма рекомендаций (группа B) по сравнению со старым (группа A) в условиях асимметричного и зашумленного распределения данных.


## Описание данных

В датасете `ab_test_results.csv` содержатся данные о 10 000 пользователей (по 5 000 в каждой группе):

* `user_id` — уникальный идентификатор пользователя
* `group` — группа (A — контроль, B — тест)
* `total_watch_time_min` — общее время просмотра за тест (в минутах)



## Что было сделано

1.  Загружен датасет и рассчитана описательная статистика для обеих групп.
2.  Проведен тест Манна-Уитни (Mann-Whitney U test) для проверки гипотезы о различии распределений.
3.  Рассчитана разница между группами в 75-м, 90-м и 95-м перцентилях для выявления асимметричного влияния.
4.  Построен график плотности распределения (KDE) для наглядной демонстрации разницы в хвостах.
5.  Сформулированы итоговые выводы и рекомендации по запуску алгоритма.


## Основные результаты
*   Среднее время просмотра в группе B выше (71.48 мин vs 56.35 мин), p-value Манна-Уитни = \*\*0.0453\*\* (значимо).
*   Эффект сконцентрирован в правом хвосте: разница в 95-м перцентиле составляет \*\*34.3 минуты\*\* (119.3 у A против 153.6 у B), в то время как медиана почти не изменилась.
*   **Вывод:** Алгоритм B эффективен для активных пользователей ("супер-зрителей"), но на пассивных влияет слабо.
